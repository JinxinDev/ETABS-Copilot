# Artificial Intelligence Design Agent for Automated Operation of Structural Software

> **Jinxin Chen, Yi Bao** — Department of Civil, Environmental and Ocean Engineering,
> Stevens Institute of Technology, Hoboken, NJ 07030, USA

This repository contains the datasets, case study model, and experimental results
supporting the paper:

**Chen, J., & Bao, Y. (2026). Artificial intelligence design agent for automated
operation of structural software using knowledge graphs and numerical models.**
*Automation in Construction*, 190, 107144.
https://doi.org/10.1016/j.autcon.2026.107144

---

## Overview

The paper presents an AI design agent that automates the operation of structural
software by integrating large language models with a domain-specific knowledge graph
in a multi-agent framework. Natural language queries are converted into executable
ETABS operations spanning model setup, modification, querying, and post-processing.

On a five-story reinforced concrete building, the agent reproduced manual results
while reducing software operation time from approximately 86 minutes to 9 minutes.
Across three independent runs of a 90-query benchmark it achieved a functional
correctness of 88.9% (± 1.6%) at 44 s per query.

---

## Source code availability

**The source code of the AI agent framework is not included in this repository and is
not being distributed.**

The framework is the subject of a pending patent application assigned to Stevens
Institute of Technology. This repository provides the data, models, and results
needed to inspect and verify the reported experiments, which is the scope of the
Data Availability statement in the published paper.

The Python files in this repository are the **scripts generated by the agent** during
the reported experiments. They are provided as evidence of what the system produced.
They are not the implementation of the planning, retrieval, generation, or debugging
agents, and they will not reproduce the framework.

Inquiries about the framework should be directed to Prof. Yi Bao
(<yi.bao@stevens.edu>).

### Mapping to the paper

| Folder | Paper section | Contents |
| --- | --- | --- |
| `experimental/` | Section 6, Tables 5–9 | The 90 benchmark queries and the script generated for each |
| `real_world/` | Section 5, Tables A1–A2 | The five-story concrete building case study |

The five-story building is a designed case study, not a project building. The paper
notes in Section 7 that it does not capture the geometric, regulatory, and
coordination complexity of real projects.

### A note on units

The paper reports the case study in SI units (6.1 m grid spacing, 27.6 MPa concrete,
1.20 kPa superimposed dead load). The queries and scripts in this repository are in
US customary units (20 ft spacing, 4,000 psi concrete, 25 psf), which is how they were
issued to the agent. The two are equivalent.

## Requirements

Opening the model and reading the generated scripts requires:

- ETABS (CSI structural analysis software), for `office.EDB`
- Python 3.x and `comtypes`, if you wish to execute the generated scripts against
  your own ETABS installation

A Gemini API key is required by the framework itself, which is not distributed here.
It is not needed to inspect anything in this repository.
